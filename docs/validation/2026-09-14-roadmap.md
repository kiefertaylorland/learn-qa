## Scope boundaries

- Mobile delivery is an installable web application; no native app-store package was created.
- Cosmetics use earned credits; no payment integration or subscription was added.
- Shared friends, matches, teams, tournaments, and public portfolios require the API deployment. GitHub Pages is a local-only demo.
- Three authored seasonal themes rotate quarterly; there are nine exclusive seasonal missions in addition to the 55 permanent challenges.
- Matches use three generated questions, server time, and polling. Unsent answers are local to the open match panel; match state and submitted results persist.
- Corporate teams use existing accounts; enterprise SSO and invoicing are outside this implementation.
