## Critical acceptance checks

Existing users retain sessions and completions. `regression-1` requires `bugs-3`, `documentation-1` requires `tests-3`, and `performance-1` requires `regression-3`; each mode then unlocks sequentially. Existing daily practice remains an explicit prerequisite exception. A new seasonal quest uses its own active-season pool and records a unique completion per season/challenge. Replaying never grants extra credits or repeated season progress.

Friend requests require recipient acceptance. Team writes require current membership and owner authority where relevant. Tournament scores use attempts started after membership/enrollment and inside the tournament window. Portfolio publication is opt-in and revocation removes public access immediately. Match score submissions accept option IDs only and are participant-bound, immutable, server-timed, and reveal answers only after competition closes.
